# Student Expense Tracker

A modern desktop expense tracker built with Python, CustomTkinter, SQLite, and Matplotlib.

## Features

- Add, edit, and delete expenses
- Monthly budget with over-budget warnings
- Category summary and spending pie chart
- Calendar view showing daily spending
- Weekly, monthly, and all-time filters
- Multi-currency support
- Light and dark themes
- Local SQLite storage
- CSV report export

## Requirements

Install the required packages:

```bash
pip install -r requirements.txt
```

## Run the app

```bash
python main.py
```

## Built with

- Python
- CustomTkinter
- SQLite
